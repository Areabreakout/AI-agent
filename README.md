# AI 炒股 Agent · 你的私人 AI 交易员

> 基于 LLM Function Calling 的 A 股智能交易助手。**不训练模型**，智能来自你自己接入的 API。

一个开源的桌面端 AI 炒股 Agent：实时行情、AI 深度分析报告、智能选股、盯盘提醒、本地浏览器登录券商实盘交易，并支持「Open 模式」让 AI 自主下单（带六层风控）。所有交易与风控代码完全开源可审计，**不含任何恶意代码**。

## ✨ 核心功能

| 模块 | 说明 |
|------|------|
| 📊 仪表盘 | 上证/深成/创业板/科创50 指数 + 自选股实时行情，30 秒自动刷新 |
| 🔍 个股分析 | 实时行情、均线/量比指标、ECharts K 线图、基本面、个股新闻 |
| 🎯 智能选股 | 放量突破 / 超跌反弹 / 均线多头 / 热门人气 四种策略全市场扫描 |
| 🔔 盯盘提醒 | 价格/涨跌幅阈值规则，后台自动轮询触发提醒 |
| 💬 AI 对话 | Agent 自动调用工具拉行情再回答，工具调用过程可折叠查看 |
| 📝 AI 深度分析报告 | 技术面 + 基本面 + 消息面 + 明确评级（买入/卖出/持有/观望）+ 价格区间 + 止损位，一键写入盯盘阈值 |
| ⚡ 实盘交易 | 本地浏览器登录你的券商账号，AI/手动填单后一键自动填充委托单，下单按钮由你人工点击 |
| 🔥 Open 模式 | AI 拥有极高权限可自主下单，强制免责声明 + 六层风控 + 全程留痕 |
| 🤖 全自动交易 | 盯盘规则触发 → AI 复核 → 风控校验 → 自动下单，支持「只记录不交易」试运行 |
| 🧪 零风险自检 | 模拟券商页验证「定位输入框 → 填单 → 点击」全链路，不产生真实交易 |
| 📋 审计日志 | 用户操作 / AI 分析 / 工具调用 / 交易执行 / 盯盘触发 全留痕 |
| 🪙 加密货币（可插拔） | 独立插件，移走 `app/plugins/tools_crypto.py` 即彻底移除 |

## 🛡️ 安全设计

- **默认人工确认**：AI 只给建议，下单按钮始终由用户点击
- **双保险**：自主下单需同时开启配置开关 + Open 模式免责声明
- **六层风控**：单笔金额上限 / 每日次数上限 / AI 置信度阈值 / 同股冷却 / 急停 / 全程留痕
- **独立浏览器实例**：固定端口 + 独立配置目录，与日常浏览器隔离，券商登录态本地保存
- **开源可审计**：所有交易相关代码公开，API Key 脱敏记录

## 🚀 快速开始

### 环境要求

- Python 3.10+
- Chrome 或 Edge 浏览器（用于自动化交易）

### 安装

```bash
pip install -r requirements.txt
```

> 可选：如需加密货币插件功能，再执行 `pip install ccxt`

### 配置

复制配置模板并填入你的 API Key：

```bash
cp config.example.json config.json
```

或直接启动应用，在【设置】页面配置：
- 支持 DeepSeek / 智谱 GLM / 通义千问 / OpenAI / Kimi（任意 OpenAI 兼容格式）
- 点预设芯片一键填充服务商信息，粘贴 API Key 即可

### 启动

```bash
python main.py
```

自动弹出桌面窗口（pywebview），或浏览器访问 `http://127.0.0.1:8730`。

### 宣传片

打开 `ai-stock-promo/ai-stock-promo.html` 查看自动播放宣传片（按 F 全屏）。

## 📁 项目结构

```
ai-stock-agent/
├── main.py                  # 入口：FastAPI 服务 + pywebview 桌面窗口
├── config.example.json      # 配置模板（复制为 config.json 使用）
├── requirements.txt
├── app/
│   ├── settings.py          # 配置管理（自动备份防误写）
│   ├── llm.py               # OpenAI 兼容客户端（流式 + 工具调用）
│   ├── agent.py             # Agent 核心：Function Calling 循环 + 评级纪律
│   ├── tools_astock.py      # A 股数据：腾讯/东财/新浪多源容错
│   ├── browser_trader.py    # 浏览器自动化交易（独立实例 + 断连自愈）
│   ├── watcher.py           # 后台盯盘
│   ├── auto_trader.py       # 全自动交易（六层风控）
│   ├── audit_log.py         # 审计日志
│   ├── api.py               # 后端路由（SSE 流式对话）
│   └── plugins/
│       ├── __init__.py      # 插件加载器（可装卸机制）
│       └── tools_crypto.py  # 加密货币插件（可选，移走即拆卸）
├── ui/
│   ├── index.html           # 主界面
│   └── mock_broker.html     # 交易自检模拟券商页
└── ai-stock-promo/          # 宣传片
```

## 🔌 插件机制

加密货币等扩展功能以独立插件形式存在，**完全可拆卸**：
- **拆卸**：将 `app/plugins/tools_crypto.py` 移出目录，重启应用
- **安装**：放回 `app/plugins/`，重启应用
- 核心代码不引用具体插件，新增功能只需按协议放一个文件

## 📊 数据源

## 📝 审计日志

所有操作记录在 `audit_log.jsonl`（每行一个 JSON），可程序化审计：
- 👤 `user_action` — 用户请求分析 / 对话 / 选股 / 盯盘 / 自检
- 🧠 `ai_analysis` — AI 报告评级与价格
- 🔧 `ai_tool_call` — Agent 工具调用记录
- ⚡ `trade_exec` — 交易填单与提交
- 🔔 `watch_trigger` — 盯盘规则触发
- 🤖 `auto_trade` — 全自动交易事件
- ⚙️ `config_change` — 配置变更（API Key 自动脱敏）
